# Active Directory Home Lab

## Overview

Built a hands-on Windows Active Directory lab to practice domain administration, user management, Group Policy, network troubleshooting, and common IT support tasks in a simulated environment.

## Environment

- Domain: vrodz.local
- Domain Controller: Windows Server 2019
- Client Machine: Windows 10 PRO
- Directory ServiceL Active Directory Domain Services
- Virtualization: Oracle VirtualBox

## Tasks Completed

- Created and managed domain users and security groups.
- Joined a Windows client to the Domain Controller.
- Configured and tested a workstation Group Policy Object.
- Tested domain logins and authentication.
- Practiced account lockout troubleshooting, passwords resets, and user onboarding/offboarding.
- Troubleshot domain-join connectivity issue by identifying and correcting VirtualBox network configuration problems.
- Configured a VirtualBox NAT network to enable communication between virtual machines.

## Skills Practiced

- Active Directory user and group management.
- Windows Server 2019 administration.
- Group Policy configuraion and testing.
- Domain authentication torubleshooting.
- VirtualBox networking and connectivity troubleshooting.
- VirtualBox NAT network configuration.
- Common service desk ticket scenarios.
- User account management.

## Purpose

I built this project to develop practical Windows administration and networking skills through hands-on troubleshooting and simulated IT support scenarios relevant to IT support roles.
